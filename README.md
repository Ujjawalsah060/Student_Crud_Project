# Student_Crud_Project
Performing Crud Operation  Using DTO( Data Transfer Object)

A Student DTO project built with Spring Boot and MySQL to manage student records using DTOs for structured data transfer between client and server.

Developed a Student DTO project using Java, Spring Boot, and MySQL. 🚀

✨ Key Features:

DTO (Data Transfer Object) implementation

Create and update student records

Request and response DTOs

RESTful API development

Database integration using Spring Data JPA
